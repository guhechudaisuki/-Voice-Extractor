# 单文件自动扩充参考接入记录

用户要求通用入口不能依赖多集数据。现已在同一条提取流水线中接入文件内自举：至少一段目标参考音频，加一个待提取文件即可启动，不要求历史输出、人工标签、排除角色或预建库。没有适用证据时会跳过扩充，不能保证任意输入都有输出。

## 使用与接口

- WebUI/桌面提取设置：勾选“自动扩充参考并应用（单文件可用，耗时增加）”。勾选发送 `cluster_bootstrap=true`、`cluster_identity_mode=enforce`，实际影响后续转写与导出。关闭保留原有 audit 行为。
- WebUI “字幕辅助（可选）”按目标文件填写字幕路径，支持 ASS/SSA/SRT/VTT、部分绑定和清除，文件重排不改变对应关系。字幕、排除角色和静音上下限可与自举同时使用。服务器在启动任务前检查字幕有效性，桌面原有绑定入口保留。
- Python：`PipelineOptions(cluster_bootstrap=True, cluster_identity_mode="enforce", cluster_bootstrap_max_rounds=3)`；开发诊断可显式选择 audit。off 与自举、输出全部单句与自举不可同时开启，给出中文错误。
- 核心入口：`extractor/nextgen/bootstrap_training.py::analyze_with_bootstrap`。只接收当前分析器、当前规范轮次和本文件禁止区间，不加载历史批次。
- 多文件批次逐文件建立独立库，不继承上一文件的证据。本次未提供外部参考库自动导入功能。
- 输出包含 `bootstrap/bootstrap_report.json` 和逐轮 `bank_round_XX.npz`，随现有批次搬移和 ZIP 打包。路径为目录内相对路径，搬移后有效。

## 核验规则

原始用户参考始终负责身份锚定和目标簇选择。目标簇对原参考的双通道分数至少 0.75；存在排除角色时，双通道余量至少 0.15。只从已通过整轮局部核验的目标成员收集种子，排除离群、用户禁止区间、检测到的歌声/重叠，以及最终硬否决区间。

库内按说话时长加权，两通道余弦同时至少 0.95 的证据去重，最多 500 条。原始参考占融合权重的一半，参考地板、排除余量和簇内一致性要求不随迭代降低。每轮只使用前一轮的库，不因遍历顺序改变证据。

复核某一轮次时，排除与它重叠的库向量和依赖它得到的后续向量。一个轮次的两个模型、全部时序窗口必须对同一参考配置一致通过，不能分别选取最高分拼凑结论。早先已通过的核验证书保留其证据来源；新增通过且满足入库条件的轮次可进入下一轮。默认最多 3 轮，允许 1–10 的整数；无新增即停止。

模型、规范轮次和内容指纹嵌入会复用，无需每轮重跑 UVR/VAD/STT。库保存模型/原参考/编码/源音频指纹，以及直接和传递证据依赖。它是机器伪标签，不是人工真值。

## 验证

414 项单元测试通过，包含 18 项新增测试：无历史数据的单文件实际改变局部判决、最终门控采用新判决、自身/重叠/传递依赖排除、无种子原判决不变、无跨文件继承、检测区间与硬否决传递、双通道与全部窗口不可拼凑、收敛与轮数上限、时长权重、数组损坏拒绝、功能关闭、worker 参数传递及无效选项拒绝。

184 个 Python 文件编译、3 项 Node 语法检查、git diff --check 通过。真实浏览器检查覆盖开关请求与原有簇摘要、筛选、标注保存、音频播放、撤下片段试听和旧批次降级。请求测试在浏览器内拦截，不启动额外推理任务。

真实音频使用同一个开发文件（234 个规范轮次），分别测试：

| 用户输入 | 基础局部核验 | 自举后 | 状态 |
|---|---:|---:|---|
| 单参考，无排除角色 | 0 | 0 | 无合格种子，没有构建空的伪参考库 |
| 6 段参考，无排除角色 | 4 | 4 | 成功生成文件内参考库，没有新增轮次 |
| 6 段参考，可选排除角色 | 6 | 7 | 新增 1 轮，第二轮收敛 |

三个测试均保持原始目标簇与基础已通过轮次，没有读取其他集作为训练数据。评估脚本 `evaluation/verify_single_file_bootstrap.py` 使用旧报告定位当前音频与规范边界，仅用于复现实测；生产入口不依赖该脚本、报告或人工标签。

工程汇总：`docs/cluster_bootstrap_engineering_20260930.json`。三个真实报告分别为 `cluster_bootstrap_minimal_20260930.json`、`cluster_bootstrap_reference_only_20260930.json`、`cluster_bootstrap_standard_20260930.json`，同名目录保存本次参考库和自举报告。

后续字幕 UI 收尾已完成：418 项测试、185 个 Python 文件编译、4 项 Node 语法、字幕/自举/簇试听三组浏览器检查通过。表单在 1440、1040、390 像素宽度验证，包含四项功能同时提交、目标重排/删除后字幕不串配、清除绑定和无效格式拒绝。最新工程记录见 `docs/cluster_ui_completion_20260930.json`；未追加声学质量通过结论。

## 实测限制

以上数量是 STT 前通过局部身份核验的轮次，不是最终导出数量或准确率。本次没有重跑完整六集分离/转写流程，也没有重用第 6/9/12 集调参。最小输入样本仍未产生合格轮次；新增通过轮次未经人工确认，不能据此声称错人问题已解决或历史 P4/P6 验收通过。短文件或缺少可靠目标簇时也可能没有可扩充的证据。

原始跨 13 集方案已在实施方案 §5.2 修订。生产代码中不存在具体剧集或数据集的保护清单；开发/验收隔离属于评估工作，不是功能的运行前提。本次未提交、合并或部署。
