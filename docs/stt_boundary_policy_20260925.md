# STT 边界策略

STT 只在声学身份和换人边界处理后运行。Whisper 返回多个文本片段本身不能判定换人；但在局部身份终审未完成前，也不能直接取消既有多片段导出保护。

2026-09-25 用户试听确认：`525.31–528.61` 候选的前两段 `え? / UFO?` 不是目标人物，只有 `UFOじゃなくてUFO` 属于目标人物。整段强声纹及“没有硬否决”都不能证明纯净；此前提交 c20fba2/cace14d 的直接放行是不安全改动，已经撤回该放行条件。不能把这段计入正确增量。

当前迁移策略：

- 真正的声学硬否决不受 STT 片段数量影响。
- `multi_model_anchor_excluded` 仅表示不适合作为恢复参考，不表示确认是其他人物。
- 多片段新增放行必须有 `local_identity_audit.passed=true`，且审计时间范围与当前候选完全相同。改边界后旧审计无效。
- 字幕补全只有逐段身份、整段身份、排除人物、连续性及内部换人检查全部通过后才能产生该审计。字幕文字不参与身份或 STT。
- 没有审计时保留原有短静音合并/单文本行为，其余多片段标为“局部身份尚未确认”，不谎称 STT 检出了换人。

这只是安全迁移，不代表所有输出已获局部纯净认证。全量声学终审及目标部分的完整恢复仍未完成，目标保持进行中。
