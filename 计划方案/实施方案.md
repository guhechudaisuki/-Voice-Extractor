#### （2）多原型打分函数（Multi-Prototype Scoring）
当用户提供 6 段不同情绪/场景的参考音频时，简单求均值 `mean(axis=0)` 会抵消特定声线特征。在 `rescore()` 中计算簇或轮次对 `TargetProfile` 的得分时：
```python
def _profile_score(vec: np.ndarray, centroid: np.ndarray, refs: np.ndarray | None) -> float:
    u = _unit(vec)
    c_score = float(u @ _unit(centroid))
    if refs is None or refs.ndim != 2 or refs.shape[0] < 2:
        return c_score
    # 取最匹配的 Top-2 参考原型的均值，与全局质心分取较大值（带 0.02 折减防单参考噪声）
    dots = np.sort(refs @ u)
    top2_mean = float(dots[-2:].mean())
    return max(c_score, top2_mean - 0.02)
```

#### （3）修复 `assign_target()` 的“平局自杀”与“次级目标簇丢失”
定位到 `extractor/nextgen/identity_cluster.py` 的 `assign_target()`（约第 440–475 行）：
- **现状问题**：`tied` 列表一旦发现得分在 `best.target_score - 0.02` 以内的合格簇，直接返回 `reason="ambiguous_target_cluster"` 且 `target_cluster_id=None`（导致第 4 集 0 输出）。
- **替换为“同声线家族合并（Target Cluster Union）”逻辑**：
  1. 选出 `qualified` 中综合得分最高的核心簇 `best`。
  2. 对 `qualified` 中的每一个簇 `c`：
     - 计算 `c` 与 `best` 的双通道质心余弦：
       `p_affinity = float(c.primary_centroid @ best.primary_centroid)`
       `s_affinity = float(c.secondary_centroid @ best.secondary_centroid)`
     - **同人子簇判定条件**（满足其一即并入 `target_cluster_ids`）：
       - **条件 A（高亲和子簇）**：`p_affinity >= 0.72 and s_affinity >= 0.70` 且 `c.target_margin >= margin_floor`；
       - **条件 B（双通道强参考直达）**：`c.primary_target_score >= profile.primary_reference_floor + 0.10 and c.secondary_target_score >= profile.secondary_reference_floor + 0.10 and c.target_margin >= margin_floor + 0.04`。
  3. 仅当存在另一个达标簇 `rival` **不满足上述同人条件**（即 `p_affinity < 0.68` 或 `s_affinity < 0.65`，说明是另一位不同声线的说话人），且 `rival.target_score >= best.target_score - 0.015` 时，才比较双通道平均分 `(primary_target_score + secondary_target_score) / 2` 选出优胜簇，**绝不再把整集清零**。

#### （4）废除 `max - 0.18` 离群规则，改为“稳健中位数 + Cohort AS-Norm 竞争过滤”
定位到 `assign_target()` 约第 472–500 行：
- **现状问题**：`reference = max(member_scores.values())`，凡 `< reference - 0.18` 全部标为 `outliers`。
- **新算法（结合工业界 Impostor Cohort AS-Norm 思想）**：
  1. 收集本集所有非目标簇作为天然背景冒认者队列（Impostor Cohort）：
     `non_target_clusters = [c for c in scored if c.cluster_id not in target_cluster_ids and len(c.members) >= 3]`
  2. 对每个目标簇 `tc`（`tc.cluster_id in target_cluster_ids`），计算其稳健中位数基准分：
     - `p_median = float(np.median(tc_primary_scores))`（用中位数替代最大值！）
     - `s_median = float(np.median(tc_secondary_scores))`
     - 主通道簇内下限：`p_floor = max(p_median - 0.18, profile.primary_reference_floor - 0.03)`
     - 副通道簇内下限：`s_floor = max(s_median - 0.20, profile.secondary_reference_floor - 0.03)`
  3. 对 `tc.members` 中的每个可用轮次 `turn`：
     - 计算对所属目标簇及 `best` 簇的最高得分 `p_tc, s_tc`，以及对 `profile` 的多原型得分 `p_prof, s_prof`；
     - 计算对所有 `non_target_clusters` 的最高主通道得分 `max_other_p`、均值 `mean_other_p` 与标准差 `std_other_p`，以及最高副通道得分 `max_other_s`；
     - 计算 **Cohort 竞争余量**：`cohort_margin_p = max(p_tc, p_prof) - max_other_p`，`cohort_margin_s = max(s_tc, s_prof) - max_other_s`；
     - **核心准入（`membership[turn.index] = True`）**：
       - `max(p_tc, p_prof) >= p_floor` 且 `max(s_tc, s_prof) >= s_floor`；
       - **非目标簇竞争守卫**：不能同时在主/副通道上败给或贴近某个非目标簇（即拒绝 `max_other_p > p_tc + 0.01 and max_other_s > s_tc - 0.02` 的混入外人）！
     - **边缘召回（`borderline_membership[turn.index] = True`）**：
       - 虽未达到核心准入，但 `max(p_tc, p_prof) >= p_floor - 0.05` 且 `cohort_margin_p >= 0.04`，供后续滑窗或前端 Tier B 捡漏。

#### （2）升级 `verify_temporal()`：生成连续干净子区间 `accepted_spans` 与窗口明细
定位到 `extractor/nextgen/cluster_runtime.py:verify_temporal()`（第 173–220 行）：
- **现状问题**：要求父轮次内 `all(row["accepted"] for row in rows)`，只要 1 个窗口不过，整条父轮次从 `accepted_spans` 中抹除。
- **新算法**：
  1. 窗口级判定 `check(profile)`：
     - 窗口对 `target_cluster_ids` 中任一目标簇质心 $\ge \text{primary\_median} - 0.20$ 或对参考多原型 $\ge \text{primary\_reference\_floor} - 0.02$；
     - 双通道对排除角色及高危非目标簇的余量 $\ge \text{margin}$。
     - **长句内部换气平滑（Smoothing）**：若窗口 $k$ 夹在窗口 $k-1$ 和 $k+1$ 之间，且 $k-1, k+1$ 均高分通过（$\ge \text{floor} + 0.06$），而窗口 $k$ 仅微跌 $\le 0.03$ 且未偏向任何排除角色，将窗口 $k$ 视为同人换气平滑通过。
  2. **提取连续干净子区间（Clean Sub-span Extraction）**：
     - 若整轮窗口通过率 $\ge 80\%$ 且首尾窗口均为 `True` $\rightarrow$ 整轮 `[turn.start, turn.end]` 计入 `accepted_spans`。
     - 若整轮并非全过（例如 15 秒父轮次里前 6 秒是目标、后 9 秒是别人，或反之）$\rightarrow$ **不要整轮丢弃**！遍历 `rows` 将连续 `accepted=True` 的窗口合并成子区间 `[sub_start, sub_end]`，只要 `sub_end - sub_start >= 1.15`，就将该干净子区间加入 `accepted_spans`！

### 1.3 `extractor/nextgen/cluster_gate.py`：候选句级（Candidate-Level）精准门控与 Tier A/B 分流

定位到 `extractor/nextgen/cluster_gate.py` 的 `candidate_membership()` 与 `apply_cluster_gate()`：

#### （1）候选句级核验（不再被父轮次脏尾巴连坐）
- 当判断一个原本已接受的候选句 `candidate`（`[candidate.start, candidate.end]`）是否放行时：
  1. **直接检查 `accepted_spans` 覆盖**：若 `candidate` 落在任一 `accepted_spans` 内（容差 `0.06s`），或与 `accepted_spans` 的交集时长占 `candidate.duration` 的比例 $\ge 85\%$（且交集时长 $\ge \text{min\_seconds}$），判定为覆盖通过。
  2. **候选句专属窗口检查**：若父轮次较长导致边界微偏，直接从 `local_windows` 取出与 `[candidate.start, candidate.end]` 重叠 $\ge 0.45\text{s}$ 的窗口：
     - 若这些窗口全部通过（或 $\ge 80\%$ 通过且首尾通过），直接放行该 `candidate`！
  3. **高危救援路径严审（守住 ≥95% 准确率的核心防线）**：
     - 检查 `candidate.diagnostics` 是否包含以下高危救援标记：
       `RESCUE_KEYS = ("locator_recovery", "classifier_target_rescue", "wavlm_local_rescue", "wavlm_rescue", "subtitle_sentence_restored", "experimental_island_rescued_child")`
     - **实证依据**：第 1/2/3 集所有混入目标簇的错人段（如 Ep1 `645.2-646.4`、Ep2 `782.2-784.6` / `831.4-832.7`、Ep3 `500.3-501.8` / `615.5-619.3`），要么带有上述救援标记且副通道/窗口最低分低，要么 `window_min_score < 0.56`！
     - 因此，凡满足以下任一风险特征的候选：
       - 带有 `RESCUE_KEYS` 且（`secondary_score < profile.secondary_reference_floor + 0.04` 或 `window_min_score < 0.62`）；
       - 无救援标记但内部存在低分窗口（`window_min_score < 0.56` 且未通过子区间裁切）；
       $\rightarrow$ **一律不得进入主输出 `accepted`（Tier A）**！若其属于目标簇集合（`membership` 或 `borderline_membership`），将其标记为 `candidate.diagnostics["cluster_tier"] = "borderline"`（Tier B 边缘待审池），否则标为 `"rejected"`。

### 1.4 字幕（ASS/SRT）+ STT 文本匹配度直接精裁正文（`subtitles.py`、`subtitle_assistance.py`、`pipeline.py`）

> **核心实证背景**：
> 经检查 `京吹原片音频/字幕/test.ass`，虽然该字幕组未填写 `Actor (Name)` 字段，但**每一条字幕的时间戳与单人台词是 1:1 严格对齐的**！
> 第一集所有最顽固的“混合说话人”错段（`413.0-418.0s`、`762.4-767.2s`、`930.9-939.1s`、`944.6-949.3s`），在 `test.ass` 中全都切分得干干净净（例如 `[412.86-414.59] 叶月` $\rightarrow$ `[414.91-417.23] 久美子正文` $\rightarrow$ `[417.23-417.97] 叶月`）。
> 现有代码之所以把它们粘成混合错段，是因为 `split_at_subtitle_pauses()` 要求边界必须有 `>= 0.20s` 静音才肯切，遇到动画里 `0.00s` 无缝接话就不切了！

#### （1）支持 ASS `Actor` 角色字段 + 无角色名字幕“能量谷底强制切分”（`subtitles.py` & `subtitle_assistance.py`）
1. 在 `SubtitleCue` 中新增 `actor: str = ""`（读取 `event.name.strip()`）。若用户提供带角色名的字幕，直接将同 `actor` 归组。
2. **双字幕重叠即多人重叠拦截**：在 `SubtitleGuide` 中增加 `overlapping_speech_spans()`，凡两条 `kind == "speech"` 的字幕时间重叠 $\ge 0.25\text{s}$（如第一集 `775.00-780.92s` 前后景同时说话），直接加入 `blocked_join_spans`，防止把背景喊话当成单人干净语音。
3. **升级 `split_at_subtitle_pauses()` 为“静音优先 + 零静音能量谷底切分”**：
   - 当字幕 Cue 边界 `edge` 落在一个长 VAD 块内部（`part.start + 0.55 < edge < part.end - 0.55`），且附近找不到 `>= silence_min_seconds` 的静音间隙时：
   - **不要放弃切分**！在 `[edge - 0.18, edge + 0.18]` 窗口内按 `10ms` 帧长计算 RMS 短时能量曲线，找到**能量最低谷点 `valley_time`**，只要切开后左右两侧均 $\ge 0.55\text{s}$，就在 `valley_time` 处切开！这能直接把 `[414.91-417.23]`、`[762.62-764.23]`、`[930.94-934.73]` 从混合块里完整剥离出来！

#### （2）STT 子分片文本匹配度与字幕对齐精裁正文（`pipeline.py:L6240`）
在 Whisper 转写阶段，`transcribe_spans()` 对每个候选回合返回了 1 个或多个带时间戳的子分片 `sentences`：
1. **定义文本相似度函数 `_text_similarity(stt_text: str, sub_text: str) -> float`**：
   - 去除标点与空格后，计算归一化最长公共子序列（LCS）或字符二元组（Bigram / Character IoU）重合率：
     `sim = 2.0 * lcs_len(a, b) / max(len(a) + len(b), 1)`
2. **按 STT 子分片 & 字幕匹配度精准截正文（Content-Aligned Trimming）**：
   - 当一个候选回合 `turn` 被 Whisper 转写为多个子分片 `fragments = [f_1, f_2, ...]`（或与多条字幕 Cue 相交）时：
   - 对每个子分片 `f_i`（或对应的字幕 Cue 区间）：
     - 检查 `f_i` 区间在 `ClusterAnalyzer` / `DualSpeakerVerifier` 下的局部声纹得分；
     - 若绑定了同语言字幕（如日文 `test.ass`），计算 `f_i.whisper_text` 与相交字幕 Cue `cue.text` 的文本匹配度 `sim`；
   - **自动去头尾杂音截正文**：
     - 如果首部或尾部子分片（如 `0.6s` 的 `'え？'`、`'おい'`、`'でしょ'`）声纹未达标，而中间主干子分片声纹达标（且与字幕 Cue 文本高匹配 `sim >= 0.55`）：
     - **绝不要像现在 `L6275` 那样用 `stt_identity_veto` 把整句话枪毙**！而是直接把 `turn.start` / `turn.end` 收缩到**声纹与文本双重通过的连续正文子分片区间 `[clean_start, clean_end]`**（若与字幕 Cue 匹配度 `>= 0.70` 且语言一致，可直接使用校准后的字幕正文文本作为高精 `text`）！
3. **裁切零交越与 15ms 余弦淡入淡出（`extractor/audio.py:write_clip`）**：
   - 在 `write_clip()` 中，对切出的波形首尾 `15ms`（16kHz 下 240 采样点）施加半余弦淡入淡出，彻底消除截断爆音。
### 1.5 模型强化升级：困难负例挖掘 + 原权重锚定对比损失（`training_material.py` & `model_reinforcement.py`）

1. **从 `partial_wrong` 自动提取困难负例（`launcher/training_material.py`）**：
   - 当某段标注为 `partial_wrong` 且记录了 `wrong_start`、`wrong_end`（时长 $\ge 0.6\text{s}$）时：
   - 打包训练 ZIP 时，自动将该时间段切出为独立的 `_hard_neg_<ordinal>.wav` 并赋予合成标签 `"wrong"`（困难负例）；同时若其余干净部分时长 $\ge 1.0\text{s}$，切出为 `_clean_pos_<ordinal>.wav` 赋予标签 `"correct"`！
   - 这样用户在界面上标一个“部分错人”，模型强化时就能同时学到“同场景里的目标正例”和“紧挨着目标的对手戏困难负例”。
2. **防遗忘对比损失（`launcher/model_reinforcement.py`）**：
   - 在训练 `projection` 层时，增加与初始权重 `original` 的 L2-SP 锚定正则项：`loss = bce_margin_loss + 0.05 * l2_sp_loss`，确保在小样本增量强化时不会破坏预训练特征空间。

### 4.2 补丁二（Stage 6）：Tier A 内部父子重叠消解（Canonical Dedup）+ Tier B 瘦身排序（Temporal NMS）

#### （1）消除 Tier A 内部的父子/重复片段（`extractor/nextgen/cluster_gate.py`）
定位到 `apply_cluster_gate()` 末尾的 `if mode == "enforce":` 块：

- **修改代码**：编写 `_deduplicate_tier_a(candidates)` 对 `kept + cropped` 统一做非极大值抑制消解：
  ```python
  def _deduplicate_tier_a(candidates, min_overlap=0.15):
      """消除 Tier A 内部互相重叠或包裹的冗余片段。
      优先保留：1) 非救援标记段优于救援段；2) 窗口最低分无明显短板（差值 <= 0.05）时保留更完整的长句；
      3) 若长句窗口最低分比干净子句低 0.06 以上（说明长句带了杂音尾巴），保留高纯度子句。
      """
      ordered = sorted(
          candidates,
          key=lambda c: (
              0 if any(c.diagnostics.get(k) for k in RESCUE_KEYS) else 1,
              round(c.duration, 3),
              float(getattr(c, "speaker_score", 0.0) or 0.0),
          ),
          reverse=True,
      )
      selected = []
      for cand in ordered:
          conflict = False
          for i, existing in enumerate(selected):
              ov = min(cand.end, existing.end) - max(cand.start, existing.start)
              if ov <= min_overlap:
                  continue
              # 若短子句纯度显著高于长父句（window_min 高出 0.06 以上），用高纯度子句替换污染长句
              c_wmin = _window_min(cand) or 0.0
              e_wmin = _window_min(existing) or 0.0
              if cand.duration < existing.duration and c_wmin >= e_wmin + 0.06 and ov >= 0.8 * cand.duration:
                  selected[i] = cand
              conflict = True
              break
          if not conflict:
              selected.append(cand)
      return sorted(selected, key=lambda c: (c.start, c.end))
  ```
