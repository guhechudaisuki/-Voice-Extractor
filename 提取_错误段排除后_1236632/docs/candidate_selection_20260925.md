# 局部证据与恢复候选裁决（开发中）

基点：`d3b7791`。本轮仅本地修改；没有替换桌面 EXE，没有整集重跑。
结论：修正了局部证据丢失，建立了非破坏候选选择原型；尚无新增完整正确音频的证明。

## 已复现的缺陷与实现

- 正式 `install_recovered_target` 只按几何包含关系替换已有候选，不查局部拒绝。提取原函数运行最小断言，能复现较大混合候选覆盖局部核心。
- `_recover_target_segments` 在所有局部不通过时只返回父段摘要，丢掉局部拒绝及其范围。新增直接调用正式函数的回归测试先失败，修复后通过；现在保留全部局部记录。
- 每个局部现在保存范围、`target / other / unresolved` 声学状态及父段；合并后的候选保留所有原子证据。`other` 表示模型的排除人物判断，不是人工真值。短段模型判断可能错误。
- 可选 `scored_parts` 输出复用已计算的局部声纹结果。正式多模型恢复的匹配表原先主要来自原始回合，未带评分的局部拒绝会漏进不了候选名单。本轮仅离线接入该评分路径，未改变正式放行策略。

后续接线修正：局部复核产生的子片段及其合并后的完整候选现在会进入同一 `scored_turns` 账本，供后续多模型目标子簇和边界修复使用；原始父回合仍保留作审计，不再代替子片段的局部匹配。合并复核失败时不会创建虚假的完整候选。该接线不降低任何身份、排除人物或污染门槛。

## 候选选择原型

`extractor/candidate_selection.py` 暂时仅供离线评估使用：

1. 在 16 kHz 整数样本时间轴上保存不可变局部证据，每个源/参考配置独立实例。
2. 整段分数不能覆盖局部冲突；候选未决不直接改判为其他人。
3. 新的局部正证据只能解决其自身范围内的未决问题，不能用外面的目标语音替它背书。
4. 不删除旧核心来换取更大的未确认候选；即使只截短旧核心 0.1 秒也不允许替换。
5. 待复核分支、被替换区间及决策链保留，不能把它们混入训练输出。
6. 不签发“纯净通过”证书，不绕过歌声、重叠、边界及 STT 流程。

这不是把局部低分永久作为硬拒绝的新上线规则。局部模型和边界仍会错；以下对照已经否定直接上线。
